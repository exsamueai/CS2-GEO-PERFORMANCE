CS2 GEORGIA

მაქსიმალური FPS და სტაბილური პერფორმანსის სრული გიდი

🔫 1. Viewmodel FPS Boost

რაც ნაკლები ადგილი უკავია ეკრანზე იარაღის მოდელს (Viewmodel), მით უფრო ნაკლებ რესურსს ხარჯავს თამაში. მართალია, მატება ძალიან მცირეა, მაგრამ სტაბილურობისთვის მაინც სასარგებლოა. ჩაწერეთ ეს კოდი თამაშის კონსოლში (~):

viewmodel_fov 54; viewmodel_offset_x 2; viewmodel_offset_y -2; viewmodel_offset_z -2; viewmodel_presetpos 3;

🎮 2. Steam Launch Options (გაშვების პარამეტრები)

Steam-ში დააჭირეთ CS2-ს მარჯვენა მაუსით -> Properties და ჩაწერეთ გაშვების პარამეტრები.

⚠️ მნიშვნელოვანი ნაბიჯი კოდის ჩაწერამდე:

სანამ ამას იზამთ, შედით Task Manager-ში, გადადით Performance-ზე, შემდეგ CPU-ზე და ქვედა ნაწილში ნახეთ რამდენი Logical processors გაქვთ. კოდში არსებული ციფრი 4-ის ნაცვლად ჩაწერეთ თქვენი ლოგიკური პროცესორების ზუსტი რაოდენობა!

თუ გაქვთ 4 Logical Processor:

-novid -high -threads 4 -nojoy +fps_max 0

თუ გაქვთ 6 Logical Processor:

-novid -high -threads 6 -nojoy +fps_max 0

თუ გაქვთ 8 Logical Processor:

-novid -high -threads 8 -nojoy +fps_max 0

თუ გაქვთ 12 Logical Processor:

-novid -high -threads 12 -nojoy +fps_max 0

თუ გაქვთ 16 Logical Processor:

-novid -high -threads 16 -nojoy +fps_max 0

🛑 თუ გაქვთ 20-ზე მეტი Logical Processor:

თუ გაქვთ 20, 24, 32 ან მეტი ლოგიკური პროცესორი, კოდიდან საერთოდ ამოიღეთ -threads, რადგან ახალ პროცესორებზე ამან შეიძლება FPS დაგიგდოთ ან თამაში გათიშოს. გამოიყენეთ ეს ვერსია:

-novid -high -nojoy +fps_max 0

🛠️ 3. Windows-ის ოპტიმიზაცია

  • Game Mode: ჩაწერეთ Windows-ის ძებნაში "Game Mode" და ჩართეთ (On).

  • Power Plan: დააყენეთ "Ultimate Performance" ან "High Performance"-ზე.

NVIDIA-ს პარამეტრებში (Manage 3D Settings) შეცვალეთ შემდეგი:

  • Texture Filtering - Quality: High Performance
  • Low Latency Mode: On ან Ultra

⚙️ 5. საუკეთესო In-Game პარამეტრები (თამაშის შიგნით)

  • Main Menu Background: Anubis (ყველაზე ნაკლებ რესურსს ჭამს)
  • Boost Player Contrast: Enabled (კაცების უკეთ დასანახად)
  • Model / Texture Detail: Low
  • Shader Detail: Low

  • NVIDIA Reflex Low Latency: Enabled + Boost

💾 6. თუ გაქვთ HDD (მყარი დისკი)

  • Defragment: გაუკეთეთ დისკს დეფრაგმენტაცია (Windows-ის ძებნაში ჩაწერეთ Defragment). **ყურადღება:** ეს გააკეთეთ მხოლოდ HDD-ზე, SSD-ზე არ შეიძლება!
  • SysMain-ის გათიშვა: Windows-ის ძებნაში ჩაწერეთ Services, მოძებნეთ SysMain, დააჭირეთ მარჯვენა მაუსით -> Properties, აირჩიეთ Disabled და დააჭირეთ Stop. ეს დაასვენებს თქვენს HDD დისკს.

❌ 7. Microsoft Edge-ის და ფონური პროცესების გათიშვა

ფონური პროგრამები ბევრ ოპერატიულ მეხსიერებას (RAM) და პროცესორს მოიხმარენ:

  • KILL Microsoft Edge: შედით Edge-ის პარამეტრებში (Settings -> System and performance) და გამორთეთ ოფცია "Startup boost" და "Continue running background extensions and apps when Microsoft Edge is closed". ეს სრულად აჩერებს Edge-ის პროცესებს ბექგრაუნდში.
  • ზედმეტი აპლიკაციების წაშლა: შედით Windows Settings -> Apps -> Installed Apps და წაშალეთ ყველა ის სტანდარტული ვინდოუსის აპლიკაცია, რომელსაც არასდროს იყენებთ.

🛡️ 8. Core Isolation (HVCI) გათიშვა FPS-ის მოსამატებლად

Windows-ის ეს ფუნქცია ხშირად აგდებს FPS-ს თამაშებში. მისი გათიშვა შეგიძლიათ რეესტრიდან:

  • Windows-ის ძებნაში ჩაწერეთ regedit და გახსენით (Registry Editor).
  • ზედა მისამართების ზოლში წაშალეთ სიტყვა Computer, ჩასვით ეს გზა და დააჭირეთ Enter:
KEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\DeviceGuard\Scenarios\HypervisorEnforcedCodeIntegrity
  • მარჯვენა მხარეს მოძებნეთ ფაილი Enabled, ორჯერ დააჭირეთ მას და Value Data შეუცვალეთ 1-დან 0-ზე.
  • გადატვირთეთ კომპიუტერი.

⚠️ შენიშვნა: ამის გამორთვის შემდეგ, შესაძლოა FACEIT ანტიჩეთმა მოგთხოვოთ მისი ისევ ჩართვა, თუმცა მომხმარებლების უმეტესობას პრობლემას არ უქმნის.

🏎️ 11. პროცესორის პრიორიტეტის ოპტიმიზაცია (REGISTRY EDITOR)

ნაბიჯი 1:Registry Editor შევდივართ, სადაც ამოაგდებს ფანჯარას. ნაბიჯი 2:მარჯვნივ ზევით წერია COMPUTER სერჩის ფანჯარაზე, ვშლით მას და ვწერთ ამას : Computer\HKEY_LOCAL_MACHINE\SYSTEM\ControlSet001\Control\PriorityControl ნაბიჯი 3:მარჯვნივ ამოვარდება სამი ფოლდერი, მოძებნე Win32PrioritySeparation-ეს ფოლდერი და დააჭირეთ ორჯერ, ნაბიჯი 4:ამოვარდება პატარა ფანჯარა სადაც უნდა ჩაწეროთ რიცხვი 26. მის გვერდით ორი წერტილის მოსანიშნი ნაწერია, უნდა მოვნიშნოთ Hexadecimal ვაწვებით OK-ს და დახურეთ ფანჯარა!

🎮 12. Fullscreen Optimizations გათიშვა (Input Lag Fix)

Steam-ში შევდივართ, ვაჭერთ CS2-ს მარჯვენა მაუსით, ვირჩევთ Manage -> Browse local files. ამოგდებულ ფანჯარაში შევდივართ game -> bin -> win64 ფოლდერში, სადაც ვიპოვით მთავარ cs2 ფაილს. ვაჭერთ მას მარჯვენა მაუსით, ირჩევთ Properties, გადავდივართ Compatibility ჩანართში, ვპოულობთ და ვნიშნავთ უჯრას Disable fullscreen optimizations, აქვე დაბლა ვაჭერთ Change high DPI settings უჯრას, ვნიშნავთ Override high DPI scaling behavior, ვაწვებით OK-ს, შემდეგ Apply-ს, ბოლოს OK-ს და ვხურავთ ფანჯარას!

🏎️ 13. მაქსიმალური ვიდეობარათის პრიორიტეტი (REGISTRY EDITOR)

Windows-მა რომ მთელი ძალა და რესურსი უშუალოდ თამაშს დაუთმოს, ჩაწერეთ ეს პარამეტრი რეესტრიდან:

  • ნაბიჯი 1: Windows-ის ძებნაში ჩაწერეთ regedit და გახსენით (Registry Editor).
  • ნაბიჯი 2: ზედა მისამართების ზოლში წაშალეთ სიტყვა Computer, ჩასვით ეს გზა და დააჭირეთ Enter:
Computer\HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Image File Execution Options
  • ნაბიჯი 3: მარცხენა მენიუში იპოვეთ ფოლდერი Image File Execution Options, დააჭირეთ მარჯვენა მაუსით -> New -> Key და დაარქვით cs2.exe
  • ნაბიჯი 4: ამ ახალ შექმნილ cs2.exe ფოლდერს ისევ დააჭირეთ მარჯვენა მაუსით -> New -> Key და დაარქვით PerfOptions
  • ნაბიჯი 5: შედით PerfOptions ფოლდერში, მარჯვენა ცარიელ მხარეს დააჭირეთ მარჯვენა მაუსით -> New -> DWORD (32-bit) Value და დაარქვით CpuPriorityClass
  • ნაბიჯი 6: ორჯერ დააჭირეთ ამ CpuPriorityClass ფაილს, გამოსულ პატარა ფანჯარაში (Value data) ჩაწერეთ ციფრი 3 (რაც ნიშნავს მაღალ High პრიორიტეტს).
  • ნაბიჯი 7: იქვე გვერდით (Base) აუცილებლად მონიშნეთ Hexadecimal, დააჭირეთ OK-ს და დახურეთ რეესტრის ფანჯარა!

📦 Essential Tweaks (ძირითადი)

  • Activity History: აქტივობების ისტორიის გათიშვა (ინახავს RAM-ს).
  • BitLocker: დისკების ავტომატური დაშიფვრის გათიშვა (მატებს დისკის სიჩქარეს).
  • ConsumerFeatures: ვინდოუსის ზედმეტი სარეკლამო ფუნქციების გათიშვა.
  • Delivery Optimization: აფდეითების ფონური გაზიარების გათიშვა ინტერნეტში.
  • Disk Cleanup: დისკის ზედმეტი ფაილებისგან ავტომატური გასუფთავება.
  • End Task With Right Click: მარჯვენა მაუსით პროგრამის მომენტალური გათიშვის ჩართვა.
  • File Explorer Automatic Folder Discovery: ფოლდერების ავტომატური ძებნის გათიშვა.
  • Hibernation: ჰიბერნაციის გათიშვა (ათავისუფლებს ადგილს C დისკზე).
  • Location Tracking: ლოკაციის თვალთვალის გათიშვა ბექგრაუნდში.
  • Microsoft Store Recommended Search Results: სთორის საძიებო რეკლამების გათიშვა.
  • Prevent Device Companion Apps: ზედმეტი გარე აპების დაბლოკვა.
  • Restore Point: სისტემის აღდგენის წერტილის შექმნა უსაფრთხოებისთვის.
  • Services - Set to Manual: ზედმეტი სერვისების გადაყვანა "ხელით ჩართვის" რეჟიმში.
  • Start Menu Previous Layout: სტარტ მენიუს ძველი, უფრო მსუბუქი დიზაინის დაბრუნება.
  • Telemetry: მაიკროსოფტში სისტემური მონაცემების ფარული გაგზავნის გათიშვა.
  • Temporary Files: კომპიუტერში არსებული ყველა დროებითი ფაილის წაშლა.
  • Widgets: ვინდოუსის ვიჯეტების (ამინდი, ნიუსები) სრული მოშორება.
  • Windows Platform Binary Table (WPBT): არასასურველი პროგრამების ავტო-ინსტალაციის ბლოკი.

⚙️ Advanced Tweaks (დამატებითი)

  • Background Apps: ფონური აპლიკაციების სრული გათიშვა (უძალიანესად უმატებს FPS-ს).
  • Disable Reserved Storage: აფდეითებისთვის შენახული 7 გიგაბაიტის გათავისუფლება C დისკზე.
  • File Explorer Home and Gallery: ფოლდერების მთავარი გვერდის მომენტალური გახსნა.
